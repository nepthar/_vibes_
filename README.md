Vibes
=====

This is a home for all of my 90+% vibecoded apps - ideas, tests, prototypes, etc, all of the kinds of things that I now have time for thanks to llms.

## DRPC
"Daemon RPC", as in there's a daemon in your rpc server. Listens for both jsonrpc messages AND just english. Out of band authentication, so a user can connect to a drpc server, have their llm ask it about how it works, just tell it what to do in english as a oneoff, and then instruct their llm to write a python script or similar that programatically interacts with it. The "daemon" is a first class citizen and why on earth CAN'T we just ask servers what they're up to?

## journal
a simple journaling app, designed to run kelso's platform. Trivial to deploy

## Keyspace Walk
Walk the keyspace of phone numbers, addresses, pin codes, etc. Each address is 1x1ft. See how long it takes you to get to the other side of ipv6.
